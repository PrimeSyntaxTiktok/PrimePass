Le coffre reste ouvert tant que le site reste ouvert, même si vous changez d’onglet ou utilisez une autre application. Utilisez « Verrouiller » pour le fermer immédiatement.

La restauration remplace le coffre actuel après confirmation et vérification du mot de passe.

Configuration Firebase & hébergement

La connexion Google nécessite HTTPS ou localhost, un domaine autorisé dans Firebase Authentication et Google activé. Les bibliothèques Firebase sont chargées sur Internet uniquement lors de la connexion. Ajoutez cette règle dans vos règles Firestore existantes, sans remplacer celles de vos autres sites. Vérifiez aussi qu’aucune règle globale n’autorise tout le monde.

match /primevault_v1/{uid} {
  allow read, delete: if request.auth != null
    && request.auth.uid == uid;
  allow create, update: if request.auth != null
    && request.auth.uid == uid
    && request.resource.data.keys().hasOnly(['payload', 'revision'])
    && request.resource.data.payload is string
    && request.resource.data.payload.size() < 800000
    && request.resource.data.revision is int;
}
